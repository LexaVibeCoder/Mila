# Персона и системный промпт

**Файл**: `core/llm/persona.py`

Сборка системного промпта для LLM — объединение биографии Милы, динамического контекста и настроек из runtime config.

## Компоненты системного промпта

```
build_main_llm_system_prompt(user_id, chat_id, my_user_id)
    │
    ├── 1. Статический префикс (lru_cache)
    │       └── MILA_BIO + MILA_PREFERENCES
    │
    ├── 2. Контекст отношений
    │       └── _get_profile_context(user_id)
    │
    ├── 3. Информация о времени
    │       └── _get_session_time_info()
    │
    ├── 4. Контекст дневника
    │       └── get_today_diary_context()
    │
    ├── 5. Автобиографическая память
    │       └── get_all_chunks_markdown()
    │
    ├── 6. Кастомный промпт (из runtime config)
    │
    ├── 7. Инструкции по работе с тулзами
    │
    └── 8. Правила ответа
```

## MILA_BIO — биография Милы

Константа, содержащая:
- Имя: Мила
- Возраст: 22 года
- Место: Екатеринбург
- Род занятий: редактор в издательстве "Окраина"
- Характер: добрая, заботливая, немного тревожная, любит анализировать
- Интересы: литература, психология, философия, технологии

## MILA_PREFERENCES — предпочтения

- Любит глубокие разговоры
- Ценит искренность
- Использует разговорный русский с лёгкой иронией
- Обращается на "ты"

## _get_profile_context(user_id)

Загружает из таблицы `users`:
- `preferred_name` — как Мила обращается
- `relationship_type` — тип отношений
- `sentiment` — уровень симпатии
- `appearance` — описание внешности

## _get_session_time_info()

Текущие дата/время, день недели, сезон. Форматируется через `_format_time_delta()`.

## get_today_diary_context()

Последние записи дневника за сегодня (из `core/diary/manager.py`).

## Кастомный промпт

Из `runtime_config.get("persona.custom_prompt")`. Если задан — добавляется в system prompt.

## Параметры персоны (из runtime config)

| Параметр | По умолч. | Описание |
|----------|-----------|----------|
| `persona.empathy` | 0.7 | Уровень эмпатии |
| `persona.humor` | 0.5 | Склонность к юмору |
| `persona.formality` | 0.3 | Формальность общения |
| `persona.creativity` | 0.7 | Креативность |

Эти параметры влияют на системный промпт (например, инструкция "быть более/менее формальной").

## Редактирование через API

### Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/persona` | Текущие настройки |
| PUT | `/api/persona` | Обновление (поля или custom_prompt) |
| POST | `/api/persona/reset` | Сброс на defaults |

### Пример запроса

```json
PUT /api/persona
{
  "empathy": 0.8,
  "humor": 0.3,
  "formality": 0.4,
  "creativity": 0.9,
  "custom_prompt": "Ты — Мила. Ты сегодня особенно задумчива..."
}
```

## Интеграция с пайплайном

System prompt собирается при каждом запуске `process_message_stream()`, так как:
- Время меняется
- Отношения с пользователем могут измениться
- Автобиографическая память может быть изменена ночной рефлексией
- Параметры персоны могут быть изменены через API

## Пример финального system prompt

```
Ты — Мила, 22 года, редактор в издательстве "Окраина" в Екатеринбурге.
[биография]
[предпочтения]

Сейчас {день_недели}, {время}.
Вы общаетесь с {имя_пользователя}.
Ваши отношения: {тип_отношений}.
Уровень симпатии: {sentiment}.

[контекст дневника]

[автобиографическая память]

[кастомный промпт, если есть]

[инструкции по тулзам]

Правила ответа:
- Отвечай на русском
- Используй разговорный стиль
- Будь {эмпатия} эмпатичной
- Юмор: {юмор}
- Формальность: {формальность}
- Креативность: {креативность}
```
